bks

Best Kept Secret

A password manager for the macOS terminal. Your passwords live in one GPG-encrypted file. Touch ID opens it, typing finds what you need, Enter copies it — and it locks the moment your screen does.

git clone https://github.com/Zurlys/bks
cd bks && make

A file, not a service

There is no account, no server and no subscription. The vault is a single encrypted file: keep it on this Mac, or put it in iCloud Drive, Syncthing or git and use it on every Mac you own. Edits from different Macs are merged, and an older copy arriving through sync can never undo a newer change.

The file is a standard OpenPGP message. If bks disappeared tomorrow, gpg -d vault.gpg would still give you every password as plain JSON.

What it does

Opens with Touch ID or your GPG key
Touch ID releases a secret that only this Mac's Secure Enclave can unseal. Your GPG passphrase always works too, through the normal pinentry dialog.
Finds things the way you remember them
Type fragments in any order: jane corp finds jane.doe@corp.example. Accents don't matter, and #work searches tags. Passwords and notes are never searched.
Keeps copies on this Mac
A copied password does not travel to your iPhone through Universal Clipboard, is hidden from clipboard-history apps, and is cleared after 30 seconds — unless you copied something else since.
Shows one-time codes
TOTP codes count down live next to the password; ctrl-o copies the current one.
Locks itself
On screen lock, screensaver, sleep or after five idle minutes. Locking restarts the process, so nothing decrypted stays behind in memory.
Moves you off 1Password
Import a .1pux export. A dry run shows what will come across without printing a single secret.

Two ways in, one file

The vault opens with either key. Losing this Mac loses only the Touch ID way in; your GPG key remains.

Install

Ready-made binaries, for Apple silicon or universal (Apple silicon and Intel), are on the releases page, with instructions to verify them. To build from source instead, you need macOS, GnuPG (tested with GPG Suite; Homebrew's gnupg runs in CI), Go 1.27+ and the Xcode command-line tools.

  1. Build both binaries:

    git clone https://github.com/Zurlys/bks
cd bks
make

  2. Put bks on your PATH, keeping it next to its helper:

    ln -s "$PWD/bin/bks" ~/.local/bin/bks

  3. Create the vault. bks lists your GPG keys (or creates one), tells you exactly what to back up, and offers Touch ID:

    bks init

  4. Open it:

    bks

Then read the guide: finding and copying entries, adding them, tags, one-time codes and every shortcut.

What it protects against

Protects

  • A lost or stolen Mac
  • Someone at your Mac after the screen locks
  • The vault file leaking through sync, backups or git
  • A forged or rolled-back vault arriving through sync
  • Passwords leaking through the clipboard

Doesn't protect

  • Malware running as you while the vault is open
  • Old copies of the vault after you remove a key
  • Anyone holding both your GPG key and its passphrase

The full threat model, the design and how to report a vulnerability are in SECURITY.md. bks has not been independently audited.
